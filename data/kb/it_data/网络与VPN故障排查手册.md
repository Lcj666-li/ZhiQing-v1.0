# 网络与 VPN 故障排查手册

## 1. 排查顺序

1. 物理层：网线是否插好、Wi-Fi 是否连对 SSID
2. 地址层：`ipconfig` 是否拿到 10.x 内网地址
3. 解析层：`nslookup intranet.zhiqing.local` 是否返回内网 DNS
4. 连通层：`ping` 网关、`tracert` 目标地址
5. 应用层：代理配置、证书、账号权限

## 2. 常见错误码

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| VPN 691 | 账号或密码错误 | 确认域账号（不带 @），SSO 改密后重连 |
| VPN 720 | 拨号组件异常 | 重启 Remote Access Connection Manager 服务 |
| VPN 789 | 加密协商失败 | 检查系统时间、更新 VPN 客户端 |
| 能连 VPN 但打不开内网 | 路由未下发 | 勾选全局模式，或联系 IT 加路由 |
| Wi-Fi 认证失败 | 证书过期/账号锁定 | 忘记网络重连；账号锁定走 8001 |

## 3. 无线网络说明

- `ZQ-Office`：员工专用，WPA2 企业级，用域账号认证
- `ZQ-Guest`：访客专用，口令由前台按天发放，限速 10Mbps
- `ZQ-IoT`：打印机、投屏等设备专用，员工终端不得接入

## 4. 远程接入策略

1. 出差/居家办公需提前在 OA 提交“远程接入申请”
2. 境外访问需额外申请白名单，审批周期 1 个工作日
3. VPN 会话空闲 30 分钟自动断开，重新认证即可

## 5. 升级路径

工单 4 小时未响应，可致电 8001 转二线；仍无法解决由网络组负责人介入，并在工单中记录升级原因。
