# IT 服务目录与支持流程

## 1. 服务台联系方式

- 服务热线：8001（工作日 9:00-18:00）
- 紧急故障：8002（7×24 小时）
- 工单入口：OA → IT 服务 → 提交工单
- 邮箱：it-support@zhiqing.com

## 2. 服务目录

| 服务 | 说明 | 承诺时效 |
| --- | --- | --- |
| 账号与权限 | 账号开通、密码重置、系统权限申请 | 1 个工作日 |
| 设备与软件 | 电脑配发、软件安装、外设申请 | 2 个工作日 |
| 网络与 VPN | 办公网、无线、远程接入 | 4 小时 |
| 邮箱与会议 | 邮箱扩容、会议室设备支持 | 4 小时 |
| 打印与文印 | 打印机安装、故障处理 | 1 个工作日 |

## 3. 工单分级

- P1（业务中断）：15 分钟响应，4 小时内恢复
- P2（部分影响）：30 分钟响应，1 个工作日内解决
- P3（咨询/需求）：4 小时响应，3 个工作日内处理

## 4. 提交工单的规范

1. 标题写清现象，例如“3 楼东区打印机脱机”
2. 描述中包含：发生时间、影响范围、已尝试的操作、报错截图
3. 涉及网络的工单请附 `tracert` 或 `ping` 结果
4. 工单关闭后 24 小时内可评价，评价会进入 IT 月度考核

## 5. 常见问题快速处理

- 账号锁定：等待 30 分钟自动解锁，或致电 8001 人工解锁
- VPN 691：确认域账号与密码，改密后重连
- 无法打印：检查是否选对打印机与楼层，重启 Print Spooler
- 邮箱满：清理大附件，或申请扩容至 50GB
