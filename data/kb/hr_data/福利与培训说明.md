# 福利与培训说明

## 1. 法定与补充福利

| 项目 | 说明 |
| --- | --- |
| 五险一金 | 每月 15 日前入职当月缴纳，公积金按当地上限比例 |
| 补充医疗 | 每年 3000 元额度，可附加配偶与子女 |
| 年度体检 | 入职满一年后每年一次，家属可享协议价 |
| 节日福利 | 春节、端午、中秋发放礼金或礼盒 |
| 弹性办公 | 每周可申请 1 天远程办公，需主管审批 |

## 2. 学习与成长

- 每人每年 3000 元学习基金，需事前申请且与岗位相关
- 内部技术分享每月 1 次，讲师可获得积分兑换礼品
- 认证考试（云厂商、项目管理等）通过后报销考试费
- 内部转岗：当前岗位满 12 个月可申请活水

## 3. 关怀与活动

- 生日会：每月最后一个周五
- 团建：每季度一次，人均预算 200 元
- 员工推荐奖：成功入职并过试用期，3000-10000 元

## 4. 常见问题

**Q：学习基金能买书吗？** 可以，需保留发票并注明书名。
**Q：补充医疗怎么报销？** 在员工福利平台上传发票，审核后 7 个工作日到账。
**Q：体检可以换城市吗？** 可以，在体检预约页选择异地机构即可。
