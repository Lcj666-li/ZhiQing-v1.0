# 新员工入职指引

## 1. 入职材料

- 身份证原件及复印件
- 学历、学位证书
- 原单位离职证明
- 本人银行卡（工资代发）
- 3 个月内体检报告
- 应届生另附三方协议

## 2. 入职当天流程

| 时间 | 事项 |
| --- | --- |
| 9:30 | 前台报到、拍照制卡 |
| 10:00 | 签署劳动合同与保密协议 |
| 10:30 | 领取电脑、工牌、办公用品 |
| 13:30 | 新人培训（制度、IT、安全） |
| 15:30 | 到部门报到，认识导师 |

## 3. 第一周要做的事

1. 完成 IT 账号激活与 MFA 绑定
2. 阅读《员工手册》《信息安全须知》并签署确认
3. 与导师制定 30/60/90 天目标
4. 参加当月的公司月度分享会

## 4. 试用期与转正

- 试用期 3 个月（特殊岗位 6 个月），薪资为转正后的 90%
- 试用期结束前 10 天提交转正申请
- 转正评估：主管评价 + HRBP 面谈 + 试用期目标完成度

## 5. 找谁帮忙

- 制度与福利：HRBP
- 电脑与账号：IT 服务台 8001
- 报销与借款：财务共享中心
