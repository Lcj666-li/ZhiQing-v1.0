# 钓鱼邮件与账号安全指引

## 1. 识别钓鱼邮件的五个特征

1. 发件域名与公司域名相近但不一致（如 zhiqing-cn.com）
2. 制造紧迫感：“两小时内不处理将冻结账号”
3. 要求点击链接登录或填写密码
4. 附件为 .exe、.js、.html 或加密压缩包
5. 正文有明显的排版错乱、错别字

## 2. 处置流程

1. 不点击链接、不下载附件
2. 转发至 security@zhiqing.com
3. 删除邮件并在企业微信中告知同事
4. 已点击的：立即断网 → 修改密码 → 报备 8002

## 3. 账号安全习惯

- 不同系统使用不同密码，建议使用密码管理器
- 开启多因素认证（MFA），尤其是邮箱与 VPN
- 不在公共电脑保存登录状态
- 收到“IT 索要密码”的电话一律拒绝，IT 不会索要密码

## 4. 常见诈骗话术

| 话术 | 真相 |
| --- | --- |
| “我是 IT，需要你的密码排查故障” | IT 无需密码即可排查，属于诈骗 |
| “领导让你马上转账” | 必须电话二次确认 |
| “中奖了，填表领奖” | 典型钓鱼，直接删除 |
