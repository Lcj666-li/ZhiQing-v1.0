# 信息安全与数据合规须知

## 1. 数据密级

| 级别 | 示例 | 管控要求 |
| --- | --- | --- |
| 公开 | 官网资料、招聘信息 | 可直接对外 |
| 内部 | 制度文件、会议纪要 | 仅限内部传播 |
| 秘密 | 客户名单、财务报表 | 加密存储，外发需审批 |
| 机密 | 核心算法、源代码 | 仅限授权人员内网访问 |

## 2. 禁止行为

1. 将公司资料上传至个人网盘、个人邮箱或公开论坛
2. 使用破解软件或来源不明的工具
3. 私自搭建对外服务、开放端口
4. 共用账号、共享密码
5. 在公共场合讨论敏感业务信息

## 3. 外发审批

- 内部资料外发：OA → 数据外发审批 → 数据 owner 审批
- 秘密级及以上：禁止外发；确因业务需要，需信息安全组会签并做脱敏
- 所有外发记录留痕 180 天，可审计追溯

## 4. 终端安全

- 必须开启屏幕锁定（5 分钟无操作自动锁屏）
- 统一安装终端防护软件，不得卸载
- 移动存储默认禁用，仅公司加密 U 盘可用
- 个人设备接入办公网需通过基线检查

## 5. 事件上报

发现数据泄露、可疑邮件、账号异常，立即：
1. 断网保护现场
2. 邮件至 security@zhiqing.com 或致电 8002
3. 保留截图与日志，配合调查
